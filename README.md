# ⚽ FIFA World Cup 2026 Tracker

## 📌 Project Description

A full-stack web application that allows users to explore FIFA World Cup 2026 matches, teams, stadiums, schedules, events, and interact through a real-time community chat.

Users can:

* Sign up and log in
* View all matches And new News with detailed info
* Explore stadiums and cities
* Discover events related to matches and external city activities
* Also the user can make message in Community Chat

---

## 🚀 Features

### 👤 Authentication

* User Sign Up / Login
* JWT-based authentication

### ⚽ Matches

* View match details:

  * Teams playing
  * Date & time
  * Stadium & city
  * Seat capacity
  * Stadium area
  * coach
  * Flag
  * Groups

### 🏟 Stadiums

* Stadium name
* Location (city)
* Capacity
* Area size
* events

### 🎉 Events

* Match-related events (inside stadium)
* External city events (e.g., boulevard, festivals)

### 🌍 Cities

* View all activities happening in each city


  ### 💬 Community Chat

  * The user can see and write comments
