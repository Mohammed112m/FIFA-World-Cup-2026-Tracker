# ⚽ FIFA World Cup 2026 Tracker

## 📌 Project Description

A full-stack web application that allows users to explore all matches of the FIFA World Cup 2026, including teams, stadiums, match schedules, and events.

Users can:

* Sign up and log in
* View all matches with detailed info
* Explore stadiums and cities
* Discover events related to matches and external city activities

---

## 🚀 Features

### 👤 Authentication

* User Sign Up / Login
* JWT-based authentication

### ⚽ Matches

* View match details:

  * Teams playing
  * Date & time
  * Stadium & city
  * Seat capacity
  * Stadium area

### 🏟 Stadiums

* Stadium name
* Location (city)
* Capacity
* Area size

### 🎉 Events

* Match-related events (inside stadium)
* External city events (e.g., boulevard, festivals)

### 🌍 Cities

* View all activities happening in each city
